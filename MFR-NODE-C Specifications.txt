MNCM4 (Hardware Revision R4-0)
		Measurement & Transmission:
			Measuring/Reporting period range:
				Typical: 			600 to 900 seconds
				Absolute Minimum: 	120 seconds (Subject to power and RF Duty cycle limits)

		Sensors and Inputs:
			* 2 x SDI-12 
				* 10 x Programming slots for controlling/measuring sensors
				* Physical Ports with shared bus driver
				* 12Volt DC Sensor Power persistent or on demand
			* 4 x Analog Single Ended 0 - 3.0volt input range
				* User Select between 2.5volt, 5volt and 12volt Excitation Power (persistent or on demand follows the SDI-12 power control)
			* 4 x Pulse Counter
				* Normally Open / Internally pulled up to 3.0volts
				* 3.0volt persistent power available.
			* 1 x CS506 FireStick

		Cellular Supported Features and Commands: 
			Features:
				* LTE-M CAT-M1 and NB-IoT NB2
				* BG95-M6 Modem
					Bands Supported through Cat M1 Mode:
						B1/B2/B3/B4/B5/B8/
						B12/B13/B18/B19/
						B20/B25/B26/B27/
						B28/B66/B85
					Bands Supported through Cat NB2 Mode:
						B1/B2/B3/B4/B5/B8/
						B12/B13/B18/B19/
						B20/B25/B28/B66/
						B71/B85
				* Diagnostics: 		    - Not Supported
				* Automatic Cell tower time synchronisation for MQTT message preparation (UTC Time)
			Commands:
				* modem apn				- Access Point Name (APN) 												E.g: "modem apn iot.1nce.net" for 1NCE ISP
				* modem usr				- APN Username (blank default)
				* modem pwd				- APN Password (blank default)
				* modem auth            - Modem auth: 0 = none, 1 = pap, 2 = chap, 3 = pap or chap (0 default)  E.g: "modem auth 0" for auth none.
				* modem oper			- Operator Code MCC+MNC. Needs to be set for correct operation 			E.g: "modem oper 50501" for Telstra 4G/CAT-M1 Network.
				* opmode 	            - change operation mode, 0 = CAT M1, 1 = Cat NB1, 2 = Both	 			E.g: "opmode 1" for Cat NB1.
		
		MQTT Supported Features and Settings (command and function):
			* mqtt host 			- MQTT Hostname
			* mqtt port 			- MQTT Port Number (default 1883 or 8883)
			* mqtt user 			- MQTT Username
			* mqtt pass 			- MQTT Password
			* mqtt client 			- MQTT ClientID
			* mqtt topic 			- MQTT Topic-Publish
			* mqtt qos              - MQTT QoS Level (0 or 1 only, 0 default)
			* mqtt tls              - Use MQTT over TLS (MQTTS) 1 = enable, 0 = disable
			* mqtt json             - Report in JSON rather than CSV, 1 = enable JSON mode, 0 = disable and use .csv mode.

		Microsoft Azure IoTHub Support:
			* mqtt azure          	- MQTT Connection is for Azure IoT Hub, 1 = enable azure mode (disables basic MQTT)
			* mqtt azureconn 		- Input String command to configure the endpoint
			* Requires the use of symmetric key authentication thus has a device connection string with the following pattern:
				HostName=<IOT_HUB_NAME>;DeviceId=<DEVICE_NAME>;SharedAccessKey=<PRIMARY_OR_SECONDARY_KEY>
				E.g:				"mqtt azureconn HostName=mycloudserver.com;DeviceId=MNCM4xxxx;SharedAccessKey=8Z1Yid4K25AU0pXlGadH0iIR9U9or5DUmwwQ4I0MFo=	"
			* Reference: https://learn.microsoft.com/en-us/azure/iot-hub/create-connect-device?tabs=portal
